# Implementation status

The README lists working code and generated outputs. Sessions 2–8 are no longer merely a roadmap. The seven newly supplied DOCX files in Downloads were read directly and retained as paragraph extracts in SESSION_2_8_SOURCE_EXTRACTS.json. Existing Session 1 code remains integrated.

## Still requires the students

- Exchange code with another team and record actual peer-review feedback; no review is invented here.
- Perform and record two live rehearsals and the final 10–12 minute presentation.
- Write each student's own 300–500 word reflection and personal answers to the reflection prompts.
- Review the educational semantic relationships, synthetic ratings and inferred categories before presenting; these are not verified commercial product facts.
- Complete any instructor-specific hand-drawn scrapbook requirements using the provided traces and diagrams as references.

## Deliberate limits

B-tree insertion/search is an optional educational extension; database disk pages, transactions and native tree deletion are not simulated. Minimax remains conceptual, as permitted by Session 5. No machine-learning model is trained. No claim is made that these algorithms reproduce the proprietary search stacks of commercial platforms.

The documents have cross-reference inconsistencies: Session 2 repeats heap output requirements whose tasks are in Session 3, and Session 5 references heap/BFS sessions inconsistently. Implementation follows the main task descriptions and includes A*, even though its Code Output summary emphasizes greedy search.
